# Simple TTS Reader

**Simple TTS Reader is a small clipboard reader based on Microsoft Speech API.**

Whenever you copy any text, **Simple TTS Reader** instantly converts it into spoken words. You have full control over the voice output — simply select your preferred speech engine from those installed on your system, such as Microsoft Zira. The application can also be minimized to the system tray. Plus, it is FREE and comes with an intuitive interface that makes it accessible to everyone.
