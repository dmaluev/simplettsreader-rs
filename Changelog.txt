Simple TTS Reader v2.0.3
------------------------
* New chunked mode (command-line: --chunked) can help bypass time limits of online TTS services
  by splitting large texts into smaller segments for creating long audio files
* Resolved an issue where the -t and -f parameters were not functioning correctly
  when the output was directed to a file instead of the default Speak mode


Simple TTS Reader v2.0.2
------------------------
* New command-line arguments:
  -t: Enables reading text directly from the command line for immediate processing
  -f: Allows reading text content from a specified file
* Toast notifications appear when audio files are successfully saved
* Option to save High Quality audio files
* Upon encountering an error, a log file (log.txt) is automatically generated


Simple TTS Reader v2.0.1

* Minor improvements
